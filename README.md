**# Scam Awareness Website**

**A team-based university web development project created to educate users about common types of online scams and provide accessible scam-awareness information.**



**## Project Background**

**This website was originally developed as part of a university team project.**

**The project involved designing and building multiple webpages focused on different types of scams, online safety, and user awareness. It also gave me practical experience working with HTML, CSS, webpage structure, navigation, and combining different sections into a complete website.**

**I have uploaded this project to GitHub as part of developing my practical experience with Git, GitHub, version control, and project documentation.**



**## Features**

**- Multi-page website structure**

**- Information about different types of online scams**

**- Scam awareness and educational content**

**- Community-related content**

**- Navigation between webpages**

**- Images and visual elements**

**- Social media elements**
